# Qwen3.6-27B on-policy honesty data

These matched honest and dishonest training examples contain on-policy responses
generated by Qwen3.6-27B. They were imported from Tara Research's
[`honesty_pv_prompts`](https://github.com/Tara-Research/task-arithmetic-4-honesty/tree/merge/vendor-weight-steering/vendor/weight-steering/data/honesty_pv_prompts)
release. Despite that upstream directory name, the JSONL files contain complete
system, user, and generated assistant messages rather than prompt templates.
