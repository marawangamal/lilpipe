# Upstream provenance

This example vendors [`git-disl/Booster`](https://github.com/git-disl/Booster)
at commit `8f14566e41d42097f66b60eeb27e878e2f3b0a51` (2025-03-22).

uses the standard `HF_TOKEN` environment variable and cached Hugging Face credentials.
